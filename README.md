# INFERNO — TalesRunner Couple Recruitment

GitHub Pages 업로드용 완성본입니다.

## 업로드
아래 5개 파일을 저장소 최상단(root)에 그대로 올리세요.
- index.html
- style.css
- script.js
- bgm.mp3
- README.md

`bgm.mp3`가 다른 파일들과 같은 위치에 있도록 맞춰져 있습니다.
GitHub 웹 업로드에서 BGM만 누락되면 나머지 파일을 먼저 올린 뒤 `bgm.mp3`만 따로 업로드해도 됩니다.

Pages: Settings → Pages → Deploy from a branch → main → /(root)
